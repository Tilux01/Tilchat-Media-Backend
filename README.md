# TilChat Media Backend

Media upload and delivery service for TilChat.

## About

Handles image and file uploads for TilChat, storing and serving media so chat conversations stay fast and reliable.

## Features

- File upload handling
- Media storage and serving
- Integration with the main chat API

## Tech Stack

- Node.js
- Express

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
